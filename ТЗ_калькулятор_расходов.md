# ТЗ: Калькулятор повседневных расходов (веб)

## 1. Цель
Одностраничное веб-приложение (один HTML-файл) для учёта повседневных покупок
(еда, медицина и др.) с аналитикой по месяцам. Работает офлайн в браузере,
без сервера и без базы данных.

## 2. Платформа и хранение
- **Формат:** один файл `index.html` (HTML + CSS + JS внутри, без внешних библиотек).
- **Хранение:** `localStorage` браузера (ключ `dailyExpenses`).
- **Перенос/бэкап:** кнопки «Экспорт JSON» и «Импорт JSON».
- **Привязка:** данные живут в одном браузере на одном устройстве.

## 3. Категории
- Пользователь сам создаёт, переименовывает и удаляет категории в интерфейсе.
- Стартовый набор при первом запуске: `Еда`, `Медицина`, `Другое` (можно менять).
- При удалении категории с записями — предупреждение и перенос записей в «Другое».

## 4. Запись о покупке (минимальный набор)
| Поле | Тип | Обязательное |
|---|---|---|
| Дата | дата | да, по умолчанию сегодня |
| Сумма | число > 0 | да |
| Категория | выбор из списка | да |
| Комментарий | текст | нет |

## 5. Валюта и язык
- Валюта: **₽ (рубли)**.
- Интерфейс: **русский**.

## 6. Бюджет
- Задаётся лимит на месяц (одно число на месяц).
- В шапке месяца: потрачено / лимит / остаток.
- При превышении — красная подсветка и надпись «Перерасход».

## 7. Функции (основные)
1. Добавить трату — форма сверху, быстрый ввод.
2. Список трат за выбранный месяц: сортировка по дате/сумме, редактирование, удаление.
3. Выбор месяца (переключатель ← / → или селектор).
4. Итоги за месяц по категориям — таблица: категория, сумма, доля %.
5. Графики: круговая (распределение по категориям) и столбчатая (динамика).
6. Общая сумма за месяц.
7. Экспорт/Импорт JSON.

## 8. Аналитика по месяцам
- Итоги по категориям за выбранный месяц.
- Графики: круговая + столбцы.
- Сравнение с прошлым месяцем (динамика, %).

## 9. Нефункциональные требования
- Адаптивность (телефон/десктоп).
- Работа без интернета.
- Защита ввода: сумма только положительная, дата корректная.
- Данные не покидают устройство.

## 10. Ограничения (осознанные)
- Нет синхронизации между устройствами.
- Нет многопользовательского режима.
- Графики — простые (SVG/Canvas), без тяжёлых библиотек.

## 11. Критерии готовности
1. Можно добавить/изменить/удалить трату — данные сохраняются после перезагрузки.
2. Можно создать свою категорию и записать трату в неё.
3. За выбранный месяц видно итог по каждой категории и общую сумму.
4. Видны круговая и столбчатая диаграммы.
5. Работает лимит на месяц с индикацией перерасхода.
6. Экспорт/импорт JSON восстанавливает данные.
7. Открывается как один файл двойным кликом, без сервера.
